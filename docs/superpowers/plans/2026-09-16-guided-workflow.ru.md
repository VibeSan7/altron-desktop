# План реализации управляемого рабочего процесса

[English](2026-09-16-guided-workflow.md) | Русский

> **Для агентов-исполнителей:** используйте superpowers:executing-plans. Реализуйте проверяемые части; не останавливайтесь на составлении плана.

**Цель:** Довести согласованный пользовательский цикл Altron до проверенного локального результата.

**Архитектура:** Существующие Store/API и Hermes SDK сохраняются. Жизненный цикл расширяется попытками и явными действиями пользователя; интеграция с Hermes и стартовая помощь отделяются от представления задачи. Никаких новых служб, платных проверяющих моделей или изменений Hermes core.

**Технологии:** Python 3.11+, FastAPI/Pydantic/SQLite, React 19 ESM, Hermes plugin SDK, Node test, pytest, Playwright/Electron.

**Спецификация:** `docs/superpowers/specs/2026-09-16-guided-workflow.md`.

## Фактическое завершение локального этапа

Выполнено ведущим агентом без запуска отдельной модели. Итоги и точные пакеты: `docs/DESKTOP_VERIFICATION.md`, `docs/evidence/local-candidate-0.4.0-beta.1.json`. Полный прогон: 114 Python-тестов прошли, 1 пропущен по разрешениям Windows; 27 JS-тестов прошли. Настоящий Desktop, обновление/возврат с 0.2 и 0.3 прошли. Публикации и нового live-исполнения моделью не было.

Уточнения реализации:
- Каталог подключений читается прямо через штатный SDK; отдельный `/setup` не нужен. Связанные небольшие элементы первого запуска/обзора объединены в `workspace-tools.mjs`.
- Первое сообщение `gateway.ready` не означает перезапуск сервера; смена поколения проверяется по `replay_epoch`, без сброса выполняющегося запроса при первом соединении.
- Восстановление повторно проверяет привязку runtime/stored ID внутри транзакции; наблюдение, полученное до изменения привязки, отклоняется.
- Для старой 0.3 добавлена отдельная явная отмена командного плана, который ни разу не запускался, через профиль обслуживания. История сохраняется; запрет обновления при реальных неподтверждённых запусках не ослаблен.
- Desktop-тест обновления ждёт готовности после перезапуска и проходит возможное повторное окно настройки штатной кнопкой «Выберу провайдера позже». Начальный мастер проходит явно до этого ожидания.

## Общие ограничения

Формат данных 1; чтение старых записей. Прежние запреты автоматического повтора, подмены модели, принятия работы исполнителем и записи вне выбранного проекта сохраняются. Публикация не входит в этот локальный этап.
