# Altron Desktop 0.4.0-beta.1 — public beta

English | [Russian](https://github.com/VibeSan7/altron-desktop/blob/main/docs/releases/v0.4.0-beta.1.ru.md)

A project assistant inside the official Hermes Desktop for Windows 11. Downloads require neither an invitation nor a GitHub login. This is a preview for testing, not a promise of error-free AI.

## What's new

- Cancel an unstarted plan while retaining its history.
- Recover state after a failure by checking the actual Hermes session, without a hidden retry.
- Revise the same task with feedback, attempt history, and a new launch confirmation.
- Choose or create a folder, select from configured connections, and fill a learning example without starting it automatically.
- Search, reversible archiving, a new-run limit, and safe diagnostics.
- Fixed a hang during the first connection. The separate maintenance profile can safely cancel an unstarted plan from the old 0.3 so that it no longer blocks an update.

## Download and install

**If Altron is not installed:** download `altron-0.4.0-beta.1.tar.gz` from the release's Assets. Use Hermes Desktop's profile-import action and select the file **without extracting it**. Do not choose the automatically generated GitHub Source code ZIP. Fully restart Desktop, enable **Desktop: Altron** in the plugins section, select the `altron` profile, and click **Altron** in the bottom bar. Connect your own model through Hermes's built-in settings.

**If Altron is already installed:** do not import the new archive over the existing profile or delete that profile. Keep a backup and follow the [upgrade and rollback guide](https://github.com/VibeSan7/altron-desktop/blob/main/docs/UPDATING.md). The separate `altron-maintenance-0.4.0-beta.1.tar.gz` maintenance profile supports upgrading from 0.2 or canceling an unstarted plan that blocks an upgrade from 0.3. It is not needed for a first installation.

Tested with Hermes Desktop **0.21.3**, source commit `d84ece48b8552501660be229797e2d2aa4cee8db`, and Python 3.11+. Altron does not install Hermes, replace `default`, or include shared paid access to models.

## Beta limitations

**No new real-model task execution or new model-team test was run for 0.4.** The successful model test from the earlier 0.3 is not presented as verification of 0.4. Ordinary tests and Desktop checks did not submit tasks to an external model.

Installing Hermes on a clean computer, a new account's first login, and an independent beginner's walkthrough have also not been tested. Support for every model, provider, and operating system has not been confirmed. Your selected provider may charge when you explicitly launch a task.

Report problems through [GitHub Issues](https://github.com/VibeSan7/altron-desktop/issues). Include versions and reproduction steps. Do not attach keys, `.env`, `auth.json`, an entire profile, the database, private conversations, or raw logs.
