# Altron Desktop 0.3.0-beta.1 — public beta

**Anyone can download and try it. No invitation or GitHub login is needed.** A regular GitHub account is required to report a problem through Issues.

## Downloads

- **For installation:** `altron-0.3.0-beta.1.tar.gz`. Do not extract it or choose Source code ZIP: import the profile into the official Hermes Desktop.
- **For upgrading an existing 0.2 installation:** also download `altron-maintenance-0.3.0-beta.1.tar.gz`. Do not import the main archive over an existing profile; follow UPDATING.md.
- `SHA256SUMS.txt` contains archive checksums.
- `ALTRON_DESKTOP.md` and `UPDATING.md` provide command-free instructions for installation, usage, upgrades, and rollback.
- `public-release-0.3.0-beta.1.json` contains anonymized verification results for these packages.

## Features

Multiple projects, plan approval, assigned specialists with exact models and connections, sequential handoff of verifiable files, and separate user acceptance. State persists across restarts; package verification, backups, and code rollback do not replace current projects.

## Verified

[GitHub Actions](https://github.com/VibeSan7/altron-desktop/actions/runs/35045929922) passed for commit `f701f3998679221628b554bf7327f5778a017daf`: 93 portable Python tests with no skips and 23 JavaScript tests. CI archives matched the packages tested on Windows byte for byte.

The public archives passed real Windows Desktop scenarios again: import, separate projects, persistence, rejection of an invalid connection, and an upgrade from 0.2 → 0.3 → rollback while retaining an old task and a new decision. Two real `gpt-6-astra / openai-codex` runs handed off files; their contents and SHA-256 were verified before acceptance, and no repeated execution occurred after restarting.

Local checks passed 95 Python tests (1 skipped because of Windows symlink permissions) and 23 JavaScript tests. Package contents and secrets were checked. The README describes how to run the tests and documents known limitations.

## Limitations

This is a preview for Windows 11 inside an already installed Hermes Desktop, not a standalone Hermes installer. Installing Hermes on a clean computer, a new account's first login, other operating systems, and every provider have not been tested. AI connections are configured in Hermes and may be billed by your provider. Verified files do not mean every part of an AI response is correct: the user accepts the result.
