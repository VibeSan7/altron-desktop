# Altron Desktop 0.3.0-beta.1 — публичная бета

[English](v0.3.0-beta.1.md) | Русский

**Скачать и попробовать может любой человек. Приглашение и вход в GitHub не нужны.** Для сообщения об ошибке через Issues нужен обычный GitHub-аккаунт.

## Скачать

- **Для установки:** `altron-0.3.0-beta.1.tar.gz`. Не распаковывайте и не выбирайте Source code ZIP: импортируйте этот профиль в официальном Hermes Desktop.
- **Для обновления уже установленной 0.2:** дополнительно `altron-maintenance-0.3.0-beta.1.tar.gz`. Не импортируйте основной архив поверх существующего профиля; следуйте UPDATING.md.
- `SHA256SUMS.txt` — контрольные суммы архивов.
- `ALTRON_DESKTOP.md`, `UPDATING.md` — инструкции без команд для установки, работы, обновления и возврата.
- `public-release-0.3.0-beta.1.json` — обезличенные результаты проверки этих пакетов.

## Возможности

Несколько проектов, согласование планов, назначенные специалисты с точными моделями и подключениями, последовательная передача проверяемых файлов, отдельная пользовательская приёмка. Сохранение состояния после перезапуска; проверка пакета, резервная копия и возврат кода без замены текущих проектов.

## Проверено

[GitHub Actions](https://github.com/VibeSan7/altron-desktop/actions/runs/35045929922) прошёл на коммите `f701f3998679221628b554bf7327f5778a017daf`: 93 переносимых Python-теста без пропусков и 23 JavaScript-теста. Архивы из CI побайтово совпали с испытанными в Windows.

Публичные архивы заново прошли настоящие сценарии Windows Desktop: импорт, раздельные проекты, сохранение, отказ неверного подключения, обновление 0.2 → 0.3 → возврат с сохранением старой задачи и нового решения. Два настоящих запуска `gpt-6-astra / openai-codex` передали файлы; содержимое и SHA-256 проверены до приёмки, после перезапуска повторного исполнения нет.

Локально прошли 95 Python-тестов (1 пропуск из-за разрешений Windows на symlink) и 23 JavaScript-теста. Состав пакетов и секреты проверены. В README описаны запуск проверок и известные ограничения.

## Ограничения

Это предварительная версия для Windows 11 внутри уже установленного Hermes Desktop, а не самостоятельный установщик Hermes. Чистая установка самого Hermes, первый вход нового аккаунта, другие ОС и все провайдеры не проверены. Подключение ИИ настраивается в Hermes и может тарифицироваться вашим провайдером. Проверенные файлы не означают, что любое содержание ответа ИИ правильно: результат принимает пользователь.
