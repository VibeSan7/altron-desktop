# Altron Desktop 0.4.0-beta.1 — публичная бета

[English](v0.4.0-beta.1.md) | Русский

Помощник по проектам внутри официального Hermes Desktop для Windows 11. Можно скачивать без приглашения и без входа в GitHub. Это предварительная версия для испытаний, а не обещание безошибочной работы ИИ.

## Что нового

- Отмена ещё не запущенного плана с сохранением истории.
- Восстановление состояния после сбоя по фактическому сеансу Hermes — без скрытого повторного запуска.
- Доработка той же задачи с замечаниями, историей попыток и новым подтверждением запуска.
- Выбор и создание папки, каталог настроенных подключений, учебный пример без автоматического старта.
- Поиск, обратимый архив, ограничение числа новых запусков и безопасная диагностика.
- Исправлено зависание при первом подключении. Добавлена безопасная отмена незапущенного плана старой 0.3 из отдельного профиля обслуживания, чтобы такой план не препятствовал обновлению.

## Скачать и установить

**Если Altron ещё не установлен:** скачайте `altron-0.4.0-beta.1.tar.gz` из Assets ниже. В Hermes Desktop нажмите **Импортировать профиль…** и выберите этот файл **без распаковки**. Не выбирайте автоматически создаваемый GitHub Source code ZIP. Полностью перезапустите Desktop, включите **Desktop: Altron** во **Возможности → Плагины**, выберите профиль `altron` и кнопку **Altron** в нижней строке. Собственную модель подключите штатными средствами Hermes.

**Если Altron уже установлен:** не импортируйте новый архив поверх прежнего профиля и не удаляйте профиль. Сохраните резервную копию и следуйте [инструкции обновления и возврата](https://github.com/VibeSan7/altron-desktop/blob/v0.4.0-beta.1/docs/UPDATING.md). Для перехода с 0.2 или отмены незапущенного плана, блокирующего обновление 0.3, предусмотрен `altron-maintenance-0.4.0-beta.1.tar.gz` — отдельный профиль обслуживания. Для первой установки он не нужен.

Проверено с Hermes Desktop **0.21.3**, исходники `d84ece48b8552501660be229797e2d2aa4cee8db`, Python 3.11+. Altron не устанавливает сам Hermes, не заменяет `default` и не включает общий платный доступ к моделям.

## Проверенная поставка

- Коммит выпуска: `62aa496fc2018f248111efc404b77512e7ac670f` ([PR #1](https://github.com/VibeSan7/altron-desktop/pull/1)).
- [GitHub Actions для точного коммита main](https://github.com/VibeSan7/altron-desktop/actions/runs/35062580675): **112 переносимых Python-тестов и 27 JavaScript-тестов прошли**. Отдельно проверено, что тест с реальной моделью пропускается без явного разрешения.
- Свежая локальная проверка Windows: **114 Python-тестов прошли, 1 пропущен** из-за отсутствия разрешения на создание символической ссылки; **27 JavaScript-тестов прошли**.
- Публикуемые архивы взяты из успешной сборки main на GitHub и побайтово совпали с пакетами, прошедшими проверку настоящего Desktop, обновление **0.2 → 0.4 → 0.2** и **0.3 → 0.4 → 0.3**, с сохранением старых задач и новых данных.
- Состав пакетов и все внутренние контрольные суммы проверены по явным манифестам. Исходники и история новых коммитов проверены на секреты. В установочных архивах нет пользовательских баз, переписок, `.env`, `auth.json` и проектов автора.

Приложенный `public-release-0.4.0-beta.1.json` — обезличенная запись испытаний пакетов **до публикации**. Эта страница связывает её с окончательным коммитом и успешной сборкой main. Первоначальный локальный кандидат сохранён отдельно; его суммы не относятся к файлам этого выпуска.

## Ограничения этой беты

**Новое выполнение задания реальной моделью и новая команда моделей для 0.4 не проводились.** Успешное испытание модели в прежней 0.3 не выдаётся за проверку 0.4. Обычные тесты и проверки Desktop не отправляли задания внешней модели.

Также не проверены установка самого Hermes на чистом компьютере, первый вход нового аккаунта и самостоятельный проход независимым новичком. Не подтверждена работа со всеми моделями, провайдерами и операционными системами. Возможны расходы выбранного вами провайдера при явном запуске задачи.

Ошибки: [GitHub Issues](https://github.com/VibeSan7/altron-desktop/issues). Укажите версии и шаги воспроизведения. Не прикладывайте ключи, `.env`, `auth.json`, полный профиль, базу, личные переписки или необработанные журналы.
