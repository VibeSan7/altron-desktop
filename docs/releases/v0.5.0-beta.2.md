# Altron Desktop v0.5.0-beta.2

Public beta release of the interview-led autonomous project workflow for the official Hermes Desktop.

## Highlights

- Start from an idea and conduct a saved, adaptive interview.
- Review one explicit contract covering scope, exclusions, deliverables, checks, folder and limits.
- Execute through a backend-owned coordinator that survives a closed Altron tab.
- Verify real files and native command receipts, then perform bounded repairs.
- Preserve manual and team workflows.
- Recover safely after restarts, lost acknowledgments, permission refusals and uncertain runtime state.
- Keep profile, project-folder, session, lineage and model/provider ownership explicit.
- Ship English-first documentation with a separate Russian README, profile archives, checksums and offline first-run/update guides.

## Install

1. Install the [official Hermes Desktop](https://hermes-agent.nousresearch.com/docs/user-guide/desktop).
2. Download `altron-kit-0.5.0-beta.2.zip` and its checksum file from the release assets.
3. Extract the outer ZIP only. Import `altron-0.5.0-beta.2.tar.gz` from Hermes Desktop; do not extract the inner profile archive.
4. Follow [FIRST_RUN.md](../FIRST_RUN.md), then read [DESKTOP_VERIFICATION.md](../DESKTOP_VERIFICATION.md) before using a real project.

## Known boundaries

This is a beta, not a stable release. Real-model reasoning quality is not universal. A prior authorized real-model acceptance attempt reached interview and work but stopped at a separate native `execute_code` confirmation, so it is not counted as a successful result. A clean Windows Sandbox verified WebView2, Hermes bootstrap, official Node.js 22.23.2 installation, source Desktop build/launch and profile import without replacing `default`; the bootstrap did not install Node or ship a packaged Desktop binary, and a new provider login was not tested.

Keep Hermes Desktop running for active work. Work-turn and time limits are not spending caps. Reject unexpected native permission requests. Read every delivered file and accept the result yourself.
