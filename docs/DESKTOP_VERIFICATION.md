# Проверка публичной беты 0.3.0-beta.1

Проверены именно архивы из публичного репозитория `VibeSan7/altron-desktop`, а не только исходники или старый установочный файл. Контрольные суммы и обезличенные результаты: [public-release-0.3.0-beta.1.json](evidence/public-release-0.3.0-beta.1.json).

## Среда и обычные тесты

- Windows 11, Node.js 22.23.2, Python 3.11.15; установленный Hermes с исходниками `d84ece48b8552501660be229797e2d2aa4cee8db`.
- Локально: **95 Python-тестов прошли, 1 пропущен** из-за отсутствия разрешения Windows на создание символической ссылки. Подмена платформы не использовалась.
- **23 JavaScript-теста прошли**. Проверены согласование, конкретные модели/подключения, область профиля, остановка и отсутствие скрытого повтора.
- Обычные проверки не обращаются к внешней модели; без `ALTRON_LIVE=1` тест с ИИ пропускается.
- Переносимые проверки и сборка выполняются отдельно в [GitHub Actions](https://github.com/VibeSan7/altron-desktop/actions/workflows/altron-desktop.yml). Полные Desktop-проверки выполнялись локально, а не на Linux-сервере Actions.

## Настоящий Desktop

- Новый архив импортирован штатным диалогом. Созданы два искусственных проекта; их данные разделены и сохранены после перезапуска.
- Неверное подключение отклонено без скрытой замены модели.
- Через интерфейс выполнены установка проверенного пакета и возврат, с проверкой настоящего перезапуска и сохранения базы/настроек.
- Отдельно выполнен переход с ранее выпущенной 0.2: импорт → старая задача → профиль обслуживания → обновление → новое решение → возврат кода. Обе записи сохранились; прежний код восстановлен побайтово. Файлы настроек и контрольные файлы учётных данных не заменены. Это искусственные данные, не личный профиль пользователя.

## Настоящая команда

В отдельном QA-профиле выполнены два шага через `gpt-6-astra / openai-codex`. Первый создал `result.json`, второй прочитал его и создал `handoff.json` с точной контрольной суммой исходного файла. Содержимое обоих файлов и SHA-256 проверены программно **до** нажатия приёмки. После закрытия и повторного запуска Desktop и сервера сохранены принятая задача и ровно два исполнения.

Отдельная проверяющая модель не запускалась. Это проверка существующего разрешённого подключения, не нового аккаунта. Рабочий профиль и исходный интерфейс не перенастроены; его учётные данные не копировались в пакет.

## Состав и безопасность поставки

Пакеты собираются из явных списков файлов. В них нет `.env`, `auth.json`, баз, журналов, пользовательских проектов или переписок. Лицензия MIT и уведомление о выбранных адаптациях agency-agents включены. Исполняемые файлы проверены на совпадение с исходниками поставки.

Gitleaks не нашёл секретов в подготовленных исходниках. В архивах он отметил два SHA-256 поля `plugin_api.py` в сгенерированных `release.json`; каждая сумма независимо пересчитана по соответствующему файлу. Это не ключи; правило сканера целиком не отключалось.

## Что не подтверждено

- Установка самого Hermes на чистом компьютере и первый вход нового аккаунта.
- Все провайдеры, модели, операционные системы и языки интерфейса.
- Работа без наблюдения, распределённая команда или изоляция уровня виртуальной машины.
- Качество произвольного результата ИИ: существование файла и его контрольная сумма не заменяют пользовательскую приёмку.

Это **публичная бета**, не обещание стабильного промышленного выпуска. [Установка](ALTRON_DESKTOP.md), [обновление и возврат](UPDATING.md), [воспроизводимые сценарии разработчика](LIVE_TESTING.md).
